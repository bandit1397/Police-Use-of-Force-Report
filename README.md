# 경찰 물리력 사용 매뉴얼

현장 경찰관이 **대상자 행위별 물리력 대응 5단계**, **장비별 사용 한계**, **사용 후 조치**,
**사용보고서 작성 대상과 작성요령**을 휴대폰에서 바로 찾아보는 참고 매뉴얼입니다.

- 사용: https://bandit1397.github.io/Police-Use-of-Force-Report/
- 첫 화면에서 전체 흐름(사용 전 → 사용 중 → 사용 후 → 근거)을 보고, 큰 주제를 누르면 세부 내용이 열립니다.
- 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있고, 한 번 열어 두면 오프라인에서도 동작합니다.
- **참고용 자료**입니다. 최종 판단은 현행 법령과 소속 기관 지침에 따릅니다.

## 구성

| 주제 | 내용 |
|---|---|
| ① 물리력 사용 원칙 | 물리력의 정의, 3대 원칙, 현장 판단 4단계(평가→판단→행동→재평가), 금지·유의사항 |
| ② 대상자 행위별 대응 5단계 | 순응·소극적 저항·적극적 저항·폭력적 공격·치명적 공격과 대응 수준 |
| ③ 장비별 사용 한계 | 수갑·경찰봉·방패·분사기·전자충격기·권총의 사용 요건, 금지 상황, 유의사항 |
| ④ 물리력 사용 후 조치 | 부상자 확인·조치, 현장 기록·증거 확보, 보고 계통, 고위험 사용자 보호 |
| ⑤ 사용보고서 작성 대상 | 작성 대상, 예/아니오 빠른 판단, 작성 원칙 |
| ⑥ 사용보고서 작성요령 | 5개 항목(현장 상황·위해감소노력·객관적 합리성·상응·사후조치) 작성법, 사용경위 쓰는 법, 작성 예시, 자주 빠뜨리는 것 |
| ⑦ 관련 법규 | 조문 원문 (펼쳐 보기) |

| 파일 | 내용 |
|---|---|
| `assets/content.js` | 매뉴얼 본문 (법령이 바뀌면 여기를 수정) |
| `assets/app.js` | 화면 (첫 화면, 세부 화면, 탭, 이전·다음) |
| `assets/style.css` | 디자인 (5단계 색, 내어쓰기, 다크모드) |

## 법령 기준 (2026-10-08 원문 대조)

- 경찰관 직무집행법 (법률 제21304호, 2026.7.7. 시행)
- 위해성 경찰장비의 사용기준 등에 관한 규정 (대통령령 제31380호, 2021.1.5. 시행)
- 경찰 물리력 행사의 기준과 방법에 관한 규칙 (경찰청 예규 제550호, 2019.11.24. 시행)
- 형법 (법률 제22007호, 2026.10.2. 시행)

### 처음 받은 자료와 달라진 주요 내용

- “범인 행위”를 규칙 용어인 **“대상자 행위”**로 바꿨습니다.
- 경찰봉·방패 사용 방법은 4단계(중위험)와 5단계(고위험) 모두 **경찰봉은 중요 부위가 아닌 신체 부위를 찌르거나 가격**, **방패는 강하게 압박하거나 세게 미는 행위**로 통일했습니다. 고위험은 다른 모든 물리력이 불가능하거나 무력화되고 정당방위·긴급피난 요건을 갖춘 경우의 최후의 수단입니다(규칙 3.3.2.마). 권총은 가급적 대퇴부 이하를 조준합니다(3.9.3.아).
- 부상자 확인은 신체 접촉을 동반한 물리력을 썼다면 **반드시** 해야 합니다(4.1.1.).
- 사용보고서는 **소속기관의 장**에게 보고하고, **대상자별**로 작성하며, **불발이어도** 작성합니다(4.2.1., 별지 서식).
- “부상”의 정의(병원 후송·진료가 필요한 부상)는 규칙 조문에 없는 실무 해석 기준이라 화면에 그렇게 표시했습니다.
- 사용보고서 작성요령은 현장 상황 → 위해감소노력 우선 → 객관적 합리성 → 대상자 행위와 물리력 간 상응 → 사후조치의 5개 항목 서식으로 구성했습니다. 작성 예시의 `[ ]` 칸은 실제 사건에 맞게 채우는 부분입니다.

## 내용 수정 방법

1. 국가법령정보센터에서 바뀐 조문을 확인합니다.
2. `assets/content.js`의 해당 문구와 `META`(기준일, 법령 정보)를 수정합니다.
3. `sw.js`의 `VERSION`을 올리고 커밋하면 GitHub Pages에 반영됩니다.

목록은 `['기호', '본문', [하위 목록]]` 형식으로 쓰면 줄이 바뀌어도 둘째 줄이 첫 글자에 맞춰집니다.
